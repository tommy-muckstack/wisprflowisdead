Get started

Try the browser demo

  1. Open the demo. No account or payment is needed.
  2. Follow Setup, choose your language, and select Start dictating. Allow microphone access when your browser asks.
  3. Review the result and choose Copy text to use it in another app. If speech is unavailable, type in the practice box and try the same cleanup.

Use the Mac app

The Mac app requires macOS 14.2 or later on Apple silicon. Check the current download or source-build instructions. Grant Microphone access for recording and Accessibility access for insertion into other apps. Without insertion access, use the clipboard.

Dictation and writing

In the browser, choose Auto Cleanup: None keeps the recognized transcript; Light applies conservative cleanup; Medium also simplifies three common English phrases. None skips local styles, dictionary corrections and snippet expansion. The browser's speech service may already have changed punctuation before returning text.

Use the Dictionary and Snippets panels to save personal spellings and reusable text. English styles adjust casing and punctuation. Browser cleanup uses fixed rules, so it does not reproduce open-ended AI editing. Review important text before using it.

Command mode can uppercase, lowercase, make bullet or numbered lists, trim spacing, or clean up a selected passage. With no selection, it uses the whole draft. Undo edit restores the previous draft.

The default browser shortcut is Ctrl+Alt+Space while this page has focus. Settings lets you change the shortcut and choose hold or toggle recording. It is not a global shortcut and cannot type into other apps.

Microphone and recognition
  1. Open the demo's Settings and run the microphone check. The level meter uses your browser's default input and stops after 20 seconds.
  2. If access was denied, allow the microphone for this site in your browser's site settings, then try again. Check your operating system's microphone permission too.
  3. If levels stay flat, check your selected system input, hardware mute switch and microphone connection.
  4. If levels move but recognition fails, check your connection and selected language. Speech availability depends on your browser and its provider.
  5. If speech is unavailable, use typed practice. Choose None to review raw recognition without local cleanup.

The browser demo may send audio to the browser provider's speech service. The Mac app uses its selected local speech engine instead.

Account and sign-in

The Mac app and public browser demo do not require an account. Website sign-in uses the shared yourappisdead.com account with email/password or the available Google provider.

For a forgotten password, open sign-in and choose Forgot password. Follow the email link. After signup, the confirmation screen can resend the verification email. If sign-in setup fails, choose Retry sign-in setup and check your connection.

Sign out from the Account page. Signing out ends the website session; it does not erase browser-profile history, dictionary entries or snippets. Manage that data in the demo.

For a public GitHub issue, include your browser or macOS version, what you tried and the visible error. Remove passwords, private transcripts, verification links and personal details.

Privacy and saved text

The browser demo does not keep audio recordings. Its speech provider may process audio remotely. Cleanup runs in the page. This differs from the Mac app's local recognition and local history.

Browser history is page-only by default. Its storage menu also offers 24-hour retention, keeping text until you delete it, or no history. Use Clear history to remove entries. Saved history belongs to the browser profile, not your account.

Dictionary and snippets stay in the page unless you enable Keep this library after closing the page. Turning that off removes the saved copy while retaining current-page entries; Clear library removes both. Settings has a separate remembering option. Other people using the same browser profile can access saved text.

Signing out does not remove this local data. Open the demo's history, library and Settings controls to review it. Website accounts use Firebase authentication; the Mac app does not need a website account.
