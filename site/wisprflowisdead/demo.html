      Settings

      Browser dictation settings

      Language and writing

      Language availability depends on your browser’s speech service. Cleanup and styles support English; other languages retain the recognized text.

      Keyboard shortcut

      Ctrl + Alt + Space

      Use Ctrl + Alt with a letter, number or Space; Shift is optional. Browser shortcuts work only while this page is focused. Fn and system-wide shortcuts require the Mac app. If your browser or system reserves a combination, use another one.

      Microphone

      Dictation uses the browser’s default microphone. Change the input in browser or system settings. This local check does not record or upload audio and does not guarantee that the speech service will use the same device.

      Microphone access is requested only when you start a test or dictation.
